aRchiteutis is built around a single long (tidy) count table, but every df2* / df_* function also accepts a phyloseq object directly, thanks to two bridges:

  • ps2df() — turn a phyloseq object into the long table, reproducing the multi-rank clade structure that get_counts() produces for Kraken2 reports;
  • df2ps() — the reverse conversion.

This vignette proves that interoperability end-to-end: we build a phyloseq object, round-trip it, and then run a representative slice of the same pipeline (composition, alpha diversity + statistics, beta diversity with the compositional backend, and a co-occurrence network) either on the phyloseq object itself or on its ps2df() conversion. Styling matches the getting-started vignette: a light ggpubr theme, viridis colours and ggpubr statistical layers.

1. Build a phyloseq object and round-trip it

We start from the honey-bee example data shipped with the package and turn it into a phyloseq object with df2ps(). Using the shipped data (rather than a phyloseq built-in such as GlobalPatterns) keeps the stage / hive sample metadata, which we need for the statistical comparisons below.

path <- system.file("extdata", package = "aRchiteutis")
legend <- system.file("extdata", "legend.csv", package = "aRchiteutis")

df <- get_counts(
  path = path,
  pattern = "_decont_bacteria_k2",
  legend = legend,
  trim_char = "_"
)

ps <- df2ps(df)          # species-level operational taxa + full lineage
ps

2. Composition

ps2df() output flows into the composition plots just like native data. We trim to the top genera first (rolling the rest into an “other” group) and draw the per-sample stacked bars in viridis.

psdf_top <- df_taxa_trim(psdf[psdf$clade != "S", ], top_taxa = 8)
df2composition(psdf_top)

df2donut(psdf_top)

3. Alpha diversity + statistics

We compute per-sample Shannon and Simpson indices from the species-level rows of the converted table and compare stages with a Wilcoxon test annotated by ggpubr::stat_compare_means() — viridis fills, light theme.

psdf_sp <- psdf[psdf$clade == "S", ]
alpha_tab <- psdf_sp %>%
  dplyr::group_by(sample) %>%
  dplyr::summarise(
    Shannon = abdiv::shannon(N),
    Simpson = abdiv::simpson(N),
    .groups = "drop"
  )
alpha_tab <- dplyr::left_join(alpha_tab, meta, by = "sample")
alpha_long <- tidyr::pivot_longer(alpha_tab, c("Shannon", "Simpson"),
                                  names_to = "index", values_to = "value")
head(alpha_tab)

ggpubr::ggboxplot(

    ggplot2::aes(label = ggplot2::after_stat(p.format)),

  ) +
  labs(x = NULL, y = "Diversity index")

4. Beta diversity directly on the phyloseq object

Because the beta-diversity functions call as_samovar_df() / as_samovar_matrix() internally, we can hand them the phyloseq object directly. df2beta() defaults to the genus clade, so df2beta(ps, print_df = TRUE) returns a genus-level Bray-Curtis distance matrix with no manual conversion.

d <- stats::as.dist(df2beta(ps, print_df = TRUE))
grp <- meta$stage[match(labels(d), meta$sample)]
as.matrix(d)[1:4, 1:4]
#>           m11       m12       m13       m14
#> m11 0.0000000 0.2756527 0.5678842 0.2120245
#> m12 0.2756527 0.0000000 0.5450748 0.3461133
#> m13 0.5678842 0.5450748 0.0000000 0.5310940
#> m14 0.2120245 0.3461133 0.5310940 0.0000000
set.seed(1)
vegan::adonis2(d ~ grp)
#> Permutation test for adonis under reduced model
#> Permutation: free
#> Number of permutations: 999
#> 
#> vegan::adonis2(formula = d ~ grp)
#>          Df SumOfSqs      R2      F Pr(>F)
#> Model     1  0.16018 0.09374 1.5516  0.216
#> Residual 15  1.54850 0.90626

A PCoA ordination, coloured by stage with grouping ellipses. Here we use the compositional (Aitchison) backend on the converted genus table when robCompositions is available, falling back to Bray-Curtis otherwise.

psdf_g <- psdf[psdf$clade == "G", ]
beta_method <- if (requireNamespace("robCompositions", quietly = TRUE)) {
  "aitchison"
} else {
  "bray"
}
df2beta_pcoa(psdf_g, method = beta_method, add_legend = 7, add_ellipse = 7)

A polished version with ggpubr::ggscatter() (confidence ellipses, group means, viridis):

pcoa <- ape::pcoa(as.matrix(df2beta(ps, print_df = TRUE)))
scores <- as.data.frame(pcoa$vectors[, 1:2])
names(scores) <- c("PCoA1", "PCoA2")
scores$sample <- rownames(scores)
scores <- dplyr::left_join(scores, meta, by = "sample")

ggpubr::ggscatter(
  scores, x = "PCoA1", y = "PCoA2",
  color = "stage", palette = viridis::viridis(2),
  ellipse = TRUE, ellipse.type = "norm", mean.point = TRUE,
  size = 3, alpha = 0.85
) +
  labs(title = "Genus-level PCoA from a phyloseq object")

5. Co-occurrence network directly on the phyloseq object

df2graph() / df2ggraph() also accept the phyloseq object directly (genus clade, top taxa by abundance), building the annotated tidygraph network and drawing it with the shared ggraph engine — communities in viridis.

set.seed(1)
df2ggraph(ps, top = 15, threshold = 0.3)

For NetCoMi-based association networks the phyloseq object works the same way via df2netcomi() / df2netcomi_graph(); that path needs the heavy optional NetCoMi dependency, so it is shown but not evaluated here.

res <- df2netcomi(ps, top = 15, measure = "pearson", thresh = 0.3)
df2netcomi_graph(res, plot = TRUE)
